- The analytics annual 100-share P/L bar chart follows `all_conditions_stacked`: each matching mode contributes a separate 100-share trade. Derive each year's amount from current metrics, and label the current year's range with the latest completed signal date in plain Japanese rather than `YTD` or the report-generation date.

Analytics owns both combined allocation tables and charts; the dashboard owns the unique detection history and mode links. - Keep beta report navigation and beta JavaScript asset URLs relative so the generated pages work both under the dedicated Worker and from a local `reports/` server. Use the dedicated `weak-early-beta-interactions.js` and `weak-early-beta-theme-init.js`; do not point beta pages at the Mega report scripts. Performance/monthly tables that can grow beyond 20 rows use the same progressive disclosure. Code/name search, inclusive signal-date range filters, result counts, clear, collapse, and per-device theme persistence are required behavior. On narrow screens the header tabs must be horizontally scrollable and detection rows readable as cards.

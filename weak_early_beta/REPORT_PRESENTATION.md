# Cloud 表示・集計の契約

`report_preferences.py` は台帳を書き換えず、表示用のコピーを作る。
2022 年はこのコピーからだけ除外する。原台帳・凍結済み D5 成績・検出モデルは変更しない。

初期設定は検出日の実終値 1,000 円以下、`d5_close`。
プリセットは 1,000 / 2,000 / 3,000 / 5,000 円、上限なし、自由入力。
自由入力は正の有限値・小数 2 桁まで・安全に整数の銭へ変換できる範囲とし、丸めない。
上限なしは `null` で表し、0 と区別する。

価格条件は `signal_actual_close_verified` を通過した名目実終値にだけ適用する。
上限指定時に未検証価格を含めず、件数を明記する。上限なしでは未検証の過去履歴も
参考成績として残す。canonical の `signal_close` を実終値へ流用しない。
モデルの直前観測行（通常は前営業日）の実終値 1,000 円以下という条件は従来のまま。
表示上限を広げても未検出の銘柄は復活しない。

## 同一母集団

ダッシュボード、analytics、各モードページは同じ上限・確定日設定を使用する。
資産推移、必要資金、年次、月次、勝率、騰落率、ランキング、CSV は選択された
表示用コピーから再生成する。履歴内の文字・日付・モード検索は履歴だけの追加検索。

D6 損益は `sixth_economics_verified` が必要。独立して検証した元の買付価格・数量、
D6 までの分割・併合を反映する。D5 の凍結経済を変更せず、保存時の調整価格で
D6 損益を計算しない。価格未取得と損益未検証は空欄とし、0 や D5 値で補完しない。
過去再構成と実運用観測を区別し、2026 年再構成が結果既知の過去期間である旨を示す。

## 無料境界と配信サイズ

無料履歴の銘柄を公開する条件は `sixth_endpoint_verified` のみ。
D5 確定、日付経過、単なる D6 予定日では解禁しない。未解禁銘柄の識別子、社名、
ファンダ本文、銘柄リンク、買付価格、D5/D6 価格を HTML 属性や CSV 用属性に出さない。
価格上限のクライアント判定には検証済み検出日実終値だけを使用する。

analytics の JSON に生台帳を埋め込まない。検証済み実終値の異なる各境界について、
Python が集計した `{html, metrics, monthlyMetrics}` を個別 gzip 圧縮して収録する。
`encoding: "gzip-base64-json"`、`variants[key].gzip` がその形式。
選択した 1 variant のみブラウザで解凍する。検出銘柄一覧は集計 variant の外に置き、
無料版では生成時点で厳格にマスクする。圧縮はアクセス制御の代用ではなく、解凍後も
集計データに銘柄識別子や生台帳が存在しないことをテストする。

初期値の静的 HTML は圧縮せず表示できる。exact な数値境界と
`priceBreakpointKeys` の対応で任意の入力を選択し、入力価格自体は丸めない。
`write_report` 内で full/free 共通集計を再利用し、検証済み証跡を各 endpoint ごとに
1 回だけ評価する。キャッシュは 1 回の生成に限り、異なる台帳へ持ち越さない。

各 HTML は書き出す前に 24 MiB 以下を検査する。超過した当該ファイルは上書きしない。
一連の生成でそれ以前のページが書かれている場合はあるため、生成失敗時は
一式をデプロイせず、成功した新規プレビュー出力で全ページを再検査する。

2026-10-04 のローカル検証では架空の検証済み実価格 20 種類・44 variants の
analytics が 307,148 bytes、生成 7.574 秒。これは性能測定用の架空データであり、
Cloud の運用実績ではない。実台帳への価格バックフィルは別途正規入力を検証して行う。

## テスト

```powershell
python -B -m unittest tests.test_weak_early_beta tests.test_weak_early_beta_report_preferences
```

価格境界、任意入力、2022 除外と不変性、D5 凍結/D6 独立経済、欠損、無料境界、
解凍後の識別子漏洩、全集計の同一母集団、20 件の静的ページング、サイズ上限を検査する。
実ブラウザの設定保存失敗・モバイル・テーマ・CSV の検査は別途行う。

# Cloud 全面探索の事前固定手順

対象は独立した **Cloud**。スコアリングレポート、GAS、Stable/Sniper/Megaには接続しない。現行1000円上限・5営業日後終値を変更しない。

## 比較する範囲

学習器4系統（XGBoost、HistGradientBoosting、ExtraTrees、線形SGD）それぞれ2設定、教師3種（当日の上位0.25%、売買コスト仮定0.2%を超える利益、上下50%で固定クリップした収益回帰）、教師出口5/10営業日後終値、特徴量3群（既存45、出来高系を外した価格・市場群、既存45に因果的な比率・相対強弱8項目を追加）、価格上限1000/1500/2000/3000/5000/なし。**864学習設定**を固定する。絶対出来高・価格の最低条件は現行以上を維持する。

新しい特徴量は当日までの45特徴量から作る。将来収益、価格水準の後日補正値、銘柄名、企業行動の将来発生を特徴に使わない。標準化は学習標本だけで行う。正例重みの算定、当日横断順位、学習CDFは各価格上限の学習集合で再計算する。

まず2023-03、2023-09、2024-03、2024-09の4月を月次因果学習で全設定比較する。これは計算量を抑える候補選抜であり、全24月に全設定を当てる総当たりとは区別する。スクリーニングはCDF 0.95/0.99/0.999、予測順位/低出来高倍率/低実体、地合い制約なし/市場5日中央値0以下、20出口を比較する。

各学習器×教師の上位1設定を残す（最大12設定）。残った設定について2023–2024の全24月を再学習する。政策探索はCDF 0.90/0.95/0.99/0.995/0.999、予測順位/低出来高倍率/低実体/両者順位平均/両者一致、市場5日中央値上限なし/0/-1%、銘柄10日騰落上限なし/0/20%/現行57.3529%、市場1日中央値下限なし/-1%、最低出来高1倍/2倍、同一銘柄休止0/5営業日を組み合わせる。**2400検出政策×20出口**を各設定で比較する。1日に最大1銘柄、100株購入。順位の矛盾・未解決の同点はその日を隔離する。

## 選び方と検証

開発選抜は件数40以上、両年15件以上、上位3利益除外後の平均プラス、中央値0以上、大敗率（-10%以下）30%以下、0.2%コスト控除後の平均プラスを最低条件にする。順位指標は「上位3利益除外平均 + 中央値×0.25 + (勝率−50)×0.05 − 大敗率×0.10」。平均だけで選ばない。通過なしの場合は探索終了を「採用可能なし」とする。条件を緩めて合格を作らない。

全月再評価後は最大8政策を固定し、設定・政策・出口のhashを保存してから2025を計算する。2025を見て同年へ再選抜しない。候補ごとの全結果を載せ、2026は既に閲覧済みの参考評価と表示する。2023–2024自体も従来研究で閲覧済みであり、新しい未使用の開発標本ではない。

比較には同じ価格源・暦・分割併合・評価規則の現行V7を使う。同時に現行公開実績（固有銘柄平均5.4942%、勝率49.1935%、中央値0%、大敗率29.0323%）を別枠に示す。この公開値は過去の固定銘柄集合からの参考値であり、同入力の比較値とは異なる。候補の2025件数50以上かつ対応する現行件数70%以上、平均・勝率・中央値・大敗率・上位利益除外平均の悪化なし、0.2/0.5%コスト感度、必要資金、年別安定性を確認する。公開参考水準も超えているかを表示する。改善があっても本番と研究の入力・学習・検出差の説明が未完了なら採用確定とはしない。

## 価格・損益の規則

翌営業日始値で実100株購入。売却候補はシグナル日から1〜10営業日後の始値・終値。各政策の20出口は同じ銘柄集合で比較し、予定日欠落・隔離価格・未対応端株精算は全出口から除外する。教師ラベルはその教師出口の存在で判定し、未来の10日価格の有無で5日教師を欠落させない。企業行動は購入日より後・売却日までだけ株数へ反映する。

購入困難登録は検出後の成績除外であり、検出の先見情報にしない。JPX整理指定は指定公表日以降だけ検出を除外する。配当・税・貸株・板・実約定は再現しない。往復0/0.2/0.5%は感度分析の仮定であり、実コストの主張ではない。現在の生存銘柄中心の価格源、提供元企業行動の完全性、過去に閲覧した期間の探索過剰という限界が残る。

## 停止と再現

既存270fit・価格上限・出口比較は再実行しない。新しいcacheにモデル・予測・収益・hash・採択前の固定票を保存する。本番コードでの1月分の再計算と既存修正cacheの特徴量・ラベル・Tail・検出一致を確認してから新モデル探索を始める。

開始時と各処理バッチでCodex使用量を確認する。週間残20%以下は保存してheartbeatをPAUSED、人の再開指示待ち。5時間残3%以下は保存停止、heartbeatをACTIVEのまま維持し、回復と週間残20%超の両方を確認したときだけ自動再開。残量不明は作業しない。使用量確認から15分のleaseが切れたworkerは新fitを始めない。

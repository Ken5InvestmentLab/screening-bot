# Cloud 表示・集計の契約

`report_preferences.py` は台帳を書き換えず、表示用のコピーを作る。
2022 年はこのコピーからだけ除外する。原台帳・凍結済み D5 成績・検出モデルは変更しない。

初期設定は検出日の実終値 1,000 円以下、`d5_close`。
プリセットは 1,000 / 2,000 / 3,000 / 5,000 円、上限なし、自由入力。
自由入力は正の有限値・小数 2 桁まで・安全に整数の銭へ変換できる範囲とし、丸めない。
上限なしは `null` で表し、0 と区別する。

価格条件は `signal_actual_close_verified` を通過した名目実終値にだけ適用する。
各ページで公開できる母集団の中で、上限指定時に未検証価格を含めず、件数を明記する。
上限なしでは、その母集団に含まれる未検証の履歴も残すが、未検証損益は成績に含めない。
canonical の `signal_close` を実終値へ流用しない。
モデルの直前観測行（通常は前営業日）の実終値 1,000 円以下という条件は従来のまま。
表示上限を広げても未検出の銘柄は復活しない。

## 同一母集団

ダッシュボード、analytics、各モードページは同じ上限・確定日・検出年設定を使用する。
資産推移、必要資金、年次、月次、勝率、騰落率、ランキング、CSV は選択された
表示用コピーから再生成する。履歴内の文字・日付・モード検索は履歴だけの追加検索。

D6 損益は `sixth_economics_verified` が必要。独立して検証した元の買付価格・数量、
D6 までの分割・併合を反映する。D5 の凍結経済を変更せず、保存時の調整価格で
D6 損益を計算しない。価格未取得と損益未検証は空欄とし、0 や D5 値で補完しない。
過去再構成と実運用観測を区別し、2026 年再構成が結果既知の過去期間である旨を示す。

`write_report` は SHA 固定した private sidecar
`state/reviewed_endpoint_receipts.v1.json` を一度だけ明示適用して表示コピーを補完する。
`read_ledger` と原台帳は変更しない。研究資料を根拠にした価格は資料の取込時刻を
示し、元の価格提供元が取得した時刻や実運用観測と混同しない。
原台帳のD5価格・数量・経済は凍結したまま保持する。表示専用のSHA固定sidecar
`state/reviewed_actual_d5.v1.json`には、検算済み研究BASE5の実入口・実D5終値・
100株・分割併合・取得費・受取額・損益・取込時刻と、元台帳のモード別不変ハッシュを保存する。
`apply_reviewed_d5_overlay`は表示コピーへ独立証跡の列だけを追加する。
`select_report_view`はD5/D6とも、翌営業日実始値で取得した100株・コスト0を共通基準に
各出口までの企業行動を反映する。D5の原本は表示コピーの`raw_d5_*`にも保持する。
履歴の実入口・D5終値・騰落率・円損益・CSV属性も同じ変換を通す。
原台帳の調整価格を実価格へ読み替えたり、D6価格からD5価格を推測したりしない。
未照合・改変・不完全な証跡ではD5の経済を未確認とし、比較・集計へ入れない。

## 実100株D5/D6の研究cohort照合

検証済み253検出のうち、検出日実終値1,000円以下を抽出すると、2023–25年174検出、
2026年44検出。研究固定cohortの一律100株損益はD5/D6でそれぞれ
361,070.00228881836 / 430,770.00305175782円、162,300 / 205,000円と独立照合した。
元資料の浮動小数価格を保持し、表示時だけ円に丸める。

既存の約定困難による参考除外は変更しない。製品成績では2023–25年171検出の
D5/D6が320,470.00534057617 / 379,670.00610351563円、2026年42検出が
148,700 / 191,300円となる。除外対象は7997（2023-04-07）、7601（2024-02-08）、
3350（2024-08-06）、3103（2026-01-27）、6840（2026-05-21）。履歴には実価格の
参考損益を残し、グラフ・必要資金・全集計から除外する。7997はユーザー指定の
日次一値に基づく政策、他4件はJPXセッション日報に基づく政策であり、実注文の
不成立を直接証明するものではない。年度・6上限・2出口・2数量方式と固定cohortの
148照合に加え、独立Decimal・資金イベント・累積曲線36照合を実施した。

## 研究 HTML からの移植

SHA `e0e7952a2a6047062984bdb4f1b24abddf585862f75969ff99ac91947baf550c`
の原 HTML を Edge で実描画し、desktop/mobile × light/dark の配色・カード・グラフ・
年/出口/配分切替・検索 CSV を確認した。元 HTML の編集・公開メニューは移植しない。
研究固定数値や生台帳をコピーせず、`analytics.py` が現在の選択済み台帳から次を算出する。

- 一律 100 株と条件数×100 株の比較カード、同一軸の累積確定損益。
- 最低初期資金、最大保有取得額、確定損益のドローダウン、損失・集中度。
- 検出年別損益、株数/買付金額を揃える事後的参考比較、条件重複の件数と平均騰落率。
- 勝敗と数量加重の統計、重複条件別内訳、過去再構成/実運用の年別件数。

取引は同じ検出日・銘柄を 1 件、100 株口数は買付時の元の数量を数える。
参考除外・成績対象・確定・未確定の件数を明記し、損益統計と資金計算の母集団を揃える。
必要初期資金は全ての同日買付の後に売却代金を受領する保守的な事後計算。
ドローダウンは確定損益だけで、日々の含み損益を含まない。資金不足時の注文変更は行わない。
正規化は数量/金額比率での事後的縮小であり、約定可能なポートフォリオではない。

年選択は公開可能な母集団に存在する年のみ。各年・2023–2025・全期間ごとに
資金/DD/全統計を再計算する。年次合計の表示切替だけで全期間指標を代用しない。
`payload.scopes[key].years` とその年範囲の実価格境界を使用する。
全期間 variant key は従来の `exit:price`、他は `exit:scope:price`。
株数方式は既計算の 2 系列の可視性を変更し、比較カードは常に両方表示する。
analytics の集計 CSV は combined 2 方式（選択時は該当方式）を出し、
モード別 CSV は該当モードの計算を残す。集計グラフは native details で数値表も閲覧できる。
年と株数方式は端末の表示補助設定のみで、会員 API の通知条件へ送らない。

## 無料境界と配信サイズ

無料版は `released_history` で母集団を先に限定する。公開条件は
`sixth_endpoint_verified` を満たす D6 実始値の取得・検証済み履歴のみ。
同じ日・同じ銘柄の複数モードに未検証証跡が残る場合は、当該銘柄全体を無料版から除外する。
D5 確定、日付経過、単なる D6 予定日では解禁しない。

未解禁行は、件数、日付、数量、モード、実終値、損益、騰落率、価格境界を含めて
無料ページへ一切寄与しない。識別子や社名を消すだけでは、価格経路や各価格上限の
集計差分から銘柄を推測できるため不十分。HTML 属性、JSON、gzip 内の全 variants、
一覧・集計 CSV、グラフ、期間表示、最新検出日をすべて公開済み母集団から生成する。
未公開行のプレースホルダーや件数は表示せず、一般的な無料版の表示範囲だけを説明する。
有料版と無料版では母集団が異なり、成績や件数も異なる。

analytics の JSON に生台帳を埋め込まない。検証済み実終値の異なる各境界について、
Python が集計した `{html, metrics, monthlyMetrics}` を個別 gzip 圧縮して収録する。
`encoding: "gzip-base64-json"`、`variants[key].gzip` がその形式。
選択した 1 variant のみブラウザで解凍する。検出銘柄一覧は集計 variant の外に置き、
無料版では生成時点で未公開行全体を除外する。無料版の価格境界も公開済み履歴だけから
作る。圧縮はアクセス制御の代用ではなく、解凍後にも未公開行が寄与しないことをテストする。

初期値の静的 HTML は圧縮せず表示できる。exact な数値境界と
`priceBreakpointKeys` の対応で任意の入力を選択し、入力価格自体は丸めない。
`write_report` のキャッシュは full/free を分離し、検証済み証跡を各 endpoint ごとに
1 回だけ評価する。キャッシュキーには公開範囲、ページ、生成日時、母集団の列型と
全値のハッシュを含める。1 回の生成で使う設計に加え、誤って異なる台帳や生成日時で
同じ辞書を再利用しても集計が混線しないことを回帰テストする。

各 HTML は書き出す前に 24 MiB 以下を検査する。超過した当該ファイルは上書きしない。
一連の生成でそれ以前のページが書かれている場合はあるため、生成失敗時は
一式をデプロイせず、成功した新規プレビュー出力で全ページを再検査する。

研究資料補完後の実規模検証では、234 種の実価格境界・年別範囲を含む
1,378 variants のダッシュボードが full 22,072,352 bytes / free 22,066,307 bytes。
ローカル生成時間は full 155.11 秒 / free 97.02 秒で、24 MiB の検査を通過した。
集計キャッシュは期間・集計入力全値・型・index・日時のハッシュで照合し、
公開済み母集団と同一になった数値集計だけを再利用する。異なる入力や公開前の行に
由来する結果を無料版へ移さないことを回帰で検査する。
デスクトップ・スマホ寸法の描画は実ブラウザで検査したが、携帯回線の転送時間・
低性能端末での応答時間は未評価。圧縮済み全 variants を含む初回 HTML 転送は大きい。
24 MiB guard までの余裕は約 3.1 MB にとどまる。価格の種類・年数が増えて上限を
超えた場合は生成を停止し、一部だけ生成された出力をデプロイしない。
これらの転送量と残り容量は、本番公開前に確認が必要な現実の制限として扱う。
この一括埋込の測定は旧チェックポイント。現在の生成では初期条件だけを HTML 内に
残し、他の条件を同じディレクトリの `weak_early_beta_data_*.json` へ分割する。
各 JSON は最大4 variants・160KB以下で、ブラウザは要求時だけ取得する。
初期画面の辞書 `sharedHtml` へ共通の表見出しや説明を一度だけ保存し、各 variant
のトークンを1回だけ展開する。銘柄履歴やファンダ本文は共有辞書へ移さない。

参照には audience、ページ、16桁 snapshot、chunk を含め、JSON本体の同じ値を照合する。
full/free は生成元、ファイル名、キャッシュを分離する。無料 bundle も未解禁行を除外した
生成元だけを使う。新しい bundle の同期は16ページの参照・サイズ・schemaを検査してから
実行し、private sidecarや原台帳を公開フォルダへコピーしない。

Cloud gate は各 bundle 要求で既存Discordセッションを確認する。有料 bundle はロールと
live Whop 有料資格の両方が必要で、未知・失効・未連携・provider障害では返さない。
応答は private/no-store、Vary Cookie、same-originで、他originと変更要求は拒否する。
401/403ではブラウザのbundle・展開結果・履歴・開いたファンダ本文を破棄し、CSV/保存を
止めて再読込する。他の取得・展開失敗では直前の確定表示へ戻す。
bundleと展開済みvariantはそれぞれ最大2件だけ保持する。
動的サーバー集計は追加せず、全集計はPythonで生成する。
生成成功後に同じ出力フォルダの古いCloud bundleだけを除去する。失敗時は旧bundleと
private資料を保持する。生成bundleはGitへ追加せず、専用Cloud tag deployで対象commitの
台帳からHTMLと同時に再生成する。承認前にこのdeploy workflowを起動しない。
新規checkoutの `npm run check` 前には、repo rootで
`python -B weak_early_beta/scripts/build_review_preview.py --output reports` を実行する。

最終実100株比較データのanalytics初回HTMLは306,111 bytes、無料版306,455 bytes。
16,232 variantsを4,062 bundlesに分け、最大131,963 bytesとなる。
4通常条件の操作可能は0.211–0.252秒、最大切替0.357秒。
模擬1.6Mbps/150ms/CPU6倍スマホは操作可能2.976秒、最大切替2.180秒。
初回総転送はライト923,243 bytes/ダーク1,804,142 bytes、制限スマホの画像取得終了9.755秒。
Edge/localhost/HTTP圧縮なし/cold cacheであり、実機・CDN・資格APIの速度は含まない。
v03はD5も検証済み実価格の100株・コスト0へ揃えたもの。原D5台帳は凍結したまま、
表示専用の固定sidecarから履歴・CSV・グラフ・資金・全集計へ同じ変換を適用する。
研究固定cohortと製品の参考除外5件は分けて照合し、除外ポリシーを変更しない。

2026-10-04 のローカル検証では架空の検証済み実価格 20 種類・44 variants の
analytics が 307,148 bytes、生成 7.574 秒。これは性能測定用の架空データであり、
Cloud の運用実績ではない。実台帳への価格バックフィルは別途正規入力を検証して行う。

## テスト

```powershell
python -B -m unittest tests.test_weak_early_beta tests.test_weak_early_beta_report_preferences
```

価格境界、任意入力、2022 除外と不変性、D5 凍結/D6 独立経済、欠損、無料境界、
解凍後の識別子漏洩、全集計の同一母集団、20 件の静的ページング、サイズ上限を検査する。
特有の価格・損益・日付を持つ D5 完了 / D6 未確定行を追加しても、無料版の HTML が
1 byte も変化しないこと、全 variants と CSV 用集計が公開済み履歴だけになることを検査する。
実ブラウザの設定保存失敗・モバイル・テーマ・CSV の検査は別途行う。

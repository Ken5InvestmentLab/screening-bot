# 価格上限の統制比較：旧価格基準の参考結果

この結果は分割対応前の同じ保存済みYahoo調整価格を使った比較である。当時の実価格・実出来高による上限判定ではなく、既存の公開成績や将来の実運用成績を示すものでもない。修正後の価格基準で行う6上限比較を最終判断に優先する。

暫定的には1,000円上限を維持する根拠がある。全体では上限撤廃によって検出数が増え、勝率と平均騰落率が下がった。2023年の銘柄均等平均だけは上限撤廃側が高く、すべての年・指標で1,000円が優位という結果ではない。

比較方法は以下の通り。

- 保存済み日足：3,700銘柄・4,061,361行、2022-01-04〜2026-09-11。評価範囲2023-01-01〜2026-09-04、45か月×2群＝90モデル。
- 訓練・予測の両方へ各価格上限を適用し、同日上位0.25%の教師ラベルも各候補母集団で作り直した。同じモデルの検出後に価格だけで絞った比較ではない。
- 45特徴量・V7の160本/深さ3/seed42/4threads・月次の `target_end_date < month_start`・Tail CDF≥0.999・固定5条件を維持。結果を見た閾値変更・条件再探索は行っていない。
- 売買評価は翌収録セッション始値から5収録セッション目終値まで、コスト0%。旧比較は収録市場日付をカレンダーに使った。修正後比較は銀行営業日カレンダーで予定日を固定する。
- 勝率は正の騰落率件数を全確定件数で割り、0%を分母に含めた。現在Cloudの `metrics.py` と一致する。
- 既存の5件の約定困難エントリー規則を両群へ適用。除外は上限1,000円17モード行、上限なし2モード行。未計測の各5モード行も確定成績に含めていない。
- 固定選定器が2024-01-18の上限1,000円/Shadowで首位同順位を検出。任意の銘柄や将来収益で順位を決めず、その1日を両群の全条件集計から除外した（上限なし3モード行が追加除外）。訓練行は変えていない。従って共通有効日による診断比較であり、厳密な公開成績再現ではない。
- 現行JPX一覧による生存バイアス、Yahooの履歴改訂、未確認の企業行動、ゼロコスト・約定保証なしという限界がある。旧調整価格による100株金額は当時の実100株損益ではないため本表の判断に使わない。

独立監査では70行の全成績を取引CSVから再集計し、勝率・平均・中央値・最悪・−10%以下・上位3件除外平均が一致した。

主な証跡は `.cache/cap_comparison_20261001/summary.json`、`metrics.csv`、`paired_metrics.csv`、`independent_audit.json`、`quarantined_dates.json`、`metrics_2023_before_common_day_exclusion.csv`。新旧基準監査は `basis_audit.json`。旧OHLC不整合797行、新ソース309行と大きな履歴改訂を確認したため、旧特徴量を修正後比較へ流用しない。

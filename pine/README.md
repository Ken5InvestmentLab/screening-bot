# 天底 JPX 50日ブレイク戦略

シグナル履歴やBotスコアを使わず、JPXの国内株を横断検証して作った日足・買い専用のTradingViewストラテジーです。`strategy()` なので「ストラテジーテスター」で銘柄ごとの過去成績を確認できます。

## 売買ルールを簡単に言うと

- **エントリー**: TOPIXが長期上昇局面にあり、20日平均売買代金3億円以上、ATRが株価の8%以下の銘柄だけを対象にします。株価が長期上昇トレンド内で、出来高が20日平均の1.2倍以上に増え、終値で過去50日高値を更新した翌日の始値に資金の50%を入れます。
- **買い増し（任意）**: 初回エントリーから`+0.75R`以上進み、終値で過去10日高値を更新した翌日の始値に残り50%を追加します。含み損でのナンピンはしません。買い増しは平均利益を上げましたが、最悪損失も広げたため初期設定はオフです。
- **損切り**: 初回価格から最大`2.5 ATR`下。ただし直近10日安値を使って無駄に広くならないよう調整し、最低でも`1 ATR`の値動き余地を残します。
- **利確**: `+1.5R`到達後は損切り線を平均取得価格以上へ上げ、EMA 20と`最高終値 - 2.5 ATR`で利益を追います。`+6R`で全利確します。`+1.5R`前はEMA 50割れ、到達後はEMA 20割れでも翌日撤退し、最長80日で終了します。

`R`は「初回価格から最初の損切りまでの値幅」です。例えば1000円で買い、最初の損切りが900円なら、`1R = 100円`、利益保護開始は1150円、最終利確は1600円です。

## TradingViewでの使い方

1. 日本株チャートを**日足・通常ローソク足**にします。
2. Pineエディタへ [`tentei_jpx_breakout_strategy.pine`](./tentei_jpx_breakout_strategy.pine) を貼り、「チャートに追加」します。
3. 「ストラテジーテスター」の概要、取引一覧、最大ドローダウンを確認します。
4. 初めは「利益が乗った時だけ1回買い増す」をオフのまま比較してください。オンにした場合は利益だけでなく最大損失も必ず比べます。

青い「買い準備」は当日終値で条件が確定した印、緑の「買い」は翌足の約定です。赤線が損切り、黄線が利益保護開始、緑線が最終利確です。

## 検証の再実行

```powershell
python pine\backtest_entry_strategy.py --max-symbols 500
```

標準設定は公式JPX上場銘柄一覧、Yahoo Financeの分割・配当調整済み日足、過去5年を使います。銘柄の80%で候補を選び、銘柄の20%は最後まで未見データとして残します。全注文は翌日始値、売買ごとに片道0.15%のコストを計上します。結果JSONと価格キャッシュは `pine/.cache/` に生成され、Git管理しません。

この戦略は将来の利益を保証しません。特に下落・レンジ相場やギャップダウンでは損失が出ます。単一銘柄の設定を後から細かく合わせ込まず、複数銘柄・異なる期間で再確認してください。
